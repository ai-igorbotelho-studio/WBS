Motion Designer prototype

Implements design/10-interaction-motion-v4.md §3, §6 rows owned by motion-designer: hero word-reveal (opacity-only), About portrait wipe + avatar ring (opacity+clip only), and the global below-fold reveal (opacity-only, IO-gated, no stagger above the fold). Reuses shipped tokens.css and motion.css by relative path — no new durations/easings invented here.

Toggling this applies the exact same end-state rules as the CSS media query (see inline <style> block above) — it does not simulate the OS setting, it duplicates the contract so reviewers without OS access can verify it.

Keyboard-nav checklist

  • Tab from the reduced-motion checkbox reaches the replay button next, in visible focus order — no element below traps or skips focus.
  • Space/Enter toggles the checkbox and activates the replay button identically to mouse click.
  • None of the three motions below (hero, about, reveal) have any keyboard-operable surface of their own — they are decorative/one-shot, so there is no focus stop expected inside .proto-hero, .proto-about, or .proto-reveal-grid (matches "decorative only" / "no keyboard path" in the v4 table).
  • Scrolling the reveal-grid stage into view via keyboard (Page Down / arrow keys) still triggers the IntersectionObserver reveal — confirmed no dependency on pointer events.
  • With the reduced-motion checkbox checked, tabbing through the page produces zero layout shift and zero animation frames (verify via devtools Rendering → paint flashing, or the automated Playwright check below).

1. Hero word-reveal — opacity-only, one shot

Communicates: reinforces the one line meant to be read first. Nothing else on the page competes for attention in the first 500ms.

Backyards built with care.

Uses --motion-base / --ease-steady from tokens.css. Opacity transition only — no transform, no clip-path, so this is a zero-CLS reveal by construction (no shape ever occupies different geometry).

2. About — portrait wipe + avatar ring, single beat

Communicates: one credibility beat (a person behind the brand), not a recurring habit — fires once, opacity+clip only, no translate.

Portrait: clip-path: inset() wipe. Ring: stroke-dashoffset draw (no fill/opacity change on the stroke itself besides the draw). Neither uses transform: translate*.

3. Global below-fold reveal — opacity-only, IO-gated, no stagger above the fold

Communicates: new content has entered view, without moving already-settled layout (the v3 16px rise is dropped — it was decoration that broke the CLS budget, per 08 §performance).
