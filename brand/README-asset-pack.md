# Waiheke Backyards Solutions — Brand Asset Pack

```
exports/
├── brand-guide/
│   └── WBS Brand Guide.html       Open in browser → Save as PDF
├── logo/
│   ├── horizontal/                Primary lockup (mark + 3-line type)
│   ├── vertical/                  Vertical V1 lockup
│   ├── all-type/                  No-icon wordmark, horizontal & vertical
│   ├── mark/                      Isolated icon
│   ├── favicon/                   App icon / browser tab
│   └── avatar/                    Round profile avatar
└── hnry/                          Files for Hnry asset production
```

Each logo variant is provided in three formats:
- **SVG** — vector master (scales infinitely, edit in Illustrator/Figma)
- **PNG** — transparent background, 3× resolution
- **JPG** — flat background, 92% quality

## Colour

- Timber `#B8845A` — RGB 184 · 132 · 90 — CMYK 22 · 47 · 67 · 6
- Bone `#F2EDE3` — RGB 242 · 237 · 227 — CMYK 3 · 3 · 9 · 0
