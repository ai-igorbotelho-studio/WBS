The call to action: timber fill with a forest label for the one primary action on a screen, a forest fill for reverse sections, or a ghost outline beside a primary. Provide `label` (a verb phrase: "Get a quote", "Call Pablo") and either `href` (renders an anchor) or `onClick`. Minimum height 48px so it is a touch target. Never place two primary buttons side by side, and never set a label under 16px on the timber fill.
