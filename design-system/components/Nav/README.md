The off-canvas nav drawer (`06-navigation-spec.md`, `09-ui-spec-v3.md` §1). Consumer provides `links` (array of `{label, href, current}`, 5 items, same order as the section they point to), `cta` (`{label, href}`), `whatsapp` (`{label, href}`), and the trigger's own `label` (defaults to "Menu"). Consumer owns wiring the trigger into the header and mounting `drawer`/`scrim` once in the DOM; the component owns everything behavioural once mounted:

- `trigger`: a 44×44px `<button aria-expanded aria-controls>` toggling the drawer; on X-morph it re-targets its own 3 `<path>` icon elements (CSS handles the transform, this just toggles `data-open`).
- `drawer`: `role="dialog" aria-modal="true" aria-label="Main menu"`, right-anchored, `drawer-width` wide, contains the link list (with the `current` row getting `aria-current="true"` and the `drawer-current-marker` left border), the CTA button and the WhatsApp link, a close button, and (mobile landscape ≤480px height) an internally-scrollable link list with header/CTA pinned via `position:sticky`.
- `scrim`: full-viewport backdrop (`--scrim` token), click-to-close.
- Behaviour, all wired internally, no consumer code required: focus trap (`Tab`/`Shift+Tab` cycle within drawer), `Escape` closes, scrim click closes, trigger toggle closes, focus restored to `trigger` on any close path, `inert` applied to every sibling of the header/drawer pair while open (consumer must ensure the drawer is mounted as a sibling of the elements it should make `inert` — pass `background` as an optional array of elements, or the component falls back to `document.body`'s direct children excluding itself), iOS-safe scroll lock (`position:fixed` + captured `scrollY`, restored with `window.scrollTo` on close), and updating `aria-current` on drawer links if the consumer calls `nav.setCurrent(href)` (mirrors the bar's own scroll-spy).
- Not decided here: scrim opacity value (owned by tokens: `scrim`), motion timing (owned by `motion.css`/tokens `--motion-fast`), and the actual bar/hamburger markup at ≥900px (frontend owns the header markup; this component covers the drawer + trigger only, reusable at every breakpoint below 900px).

Returns `{trigger, drawer, scrim, setCurrent(href), open(), close()}`. Reduced motion: the component itself does no animation (CSS owns transitions and already zeroes them under `prefers-reduced-motion`); `open()`/`close()` just toggle attributes/classes so the no-JS/reduced-motion end state is always correct.
