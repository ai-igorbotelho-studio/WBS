A single attributed testimonial, `<blockquote class="quote">` (09-ui-spec-v3 §4.6 / Head decision 2026-09-22 #3: no quote section ships by default; this component exists for when real copy arrives). Consumer provides `{text, attribution}`. **The component refuses to render a placeholder**: if `text` is empty, `null`, or only whitespace, it returns `null` (no DOM node, no comment, nothing mounted) — this is deliberate, to make it impossible for a fake/placeholder quote to reach production by accident. `attribution` is optional but recommended (renders as a `<cite>` inside the blockquote); a quote with no attribution still renders as long as `text` is present.
