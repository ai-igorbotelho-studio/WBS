Formalizes the gallery filter chip (previously a loose `.chip` class in markup) as a component, with **no visual change** (09-ui-spec-v3 §5: "no change" for chips). Consumer provides `{label, active, onToggle}`. Renders `<button type="button" class="chip" aria-pressed>`; `active` sets `aria-pressed="true"` and the pressed visual state (unchanged CSS, still `.chip[aria-pressed="true"]` in `motion.css`/`components.css`). `onToggle(nextActive)` fires on click; the component does not manage active state itself — it's a controlled component, the consumer's filter state is the source of truth (matches the existing FLIP-driven gallery filter logic in `site.js`).
